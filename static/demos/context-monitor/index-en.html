How It Works

Read-Only on Local Files, Zero Client Edits

Runs strictly within Antigravity's official Plugin, Hooks, and Sidecar rules—validated with 0 errors and 0 warnings via agy plugin validate.

01

Read-Only Local Sources

A minimal SessionStart / PreInvocation hook records the active conversation ID while reading Antigravity's existing files.

  • transcript.jsonl → tokens, tools & checkpoints
  • annotations/*.pbtxt → renamed session titles
  • conversations/*.db → read-only step timestamps
02

Zero-npm Node Sidecar

No third-party npm packages: includes a compact pure-JS Protobuf reader and read-only SQLite wrapper, quietly skipping TTFT on Node 20.

  • f1 (created_at) → f6 (viewable_at) yields true TTFT
  • 127.0.0.1 loopback only, zero outbound network calls
  • Per-launch random CONTEXT_MONITOR_HUD_TOKEN
03

Auxiliary Pane + macOS Pill

All platforms get the Sidecar Auxiliary Pane; macOS compiles a local AppKit Universal binary (arm64 + x86_64) via swiftc on first launch.

  • Aux Pane: Overview · History · Steps · Tools · Raw
  • macOS HUD: left-click popover, right-click menu
  • Apple code signature stays intact across updates
Quick Start

Install into Antigravity with One Command

Clone directly into your plugins folder and restart Antigravity, or download the prebuilt hud_bar-v0.2.0-macos-universal.tar.gz (with SHA-256 checksum) from GitHub Releases. MIT Licensed.

Read Background & Article GitHub Repository ↗
bash
git clone https://github.com/heywalter/antigravity-context-monitor.git \
  ~/.gemini/config/plugins/context-monitor

# Optional: validate & install via CLI
cd ~/.gemini/config/plugins/context-monitor
agy plugin validate . && agy plugin install .
